# Sherif Abdulazeez — Frontend Portfolio

A frontend-centered portfolio built with Next.js, TypeScript, Tailwind CSS, Motion and Lucide React.

## Featured projects

- ApplyNow — application tracking and verification platform.
- SafeNest — collaborative personal-finance planning product.
- Course Catalog — level-based course discovery platform.

The project cards and case studies use the supplied project screenshots. Screenshots are placed inside browser-style presentation frames and may be cropped/resized responsively by the browser without replacing the source visuals.

## Run locally

```bash
npm install
npm run dev
```

The dev server uses Webpack intentionally.

## Build

```bash
npm run build
```
